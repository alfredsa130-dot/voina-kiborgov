# Война киборгов — настольная игра

Добро пожаловать в репозиторий игры **«Война киборгов»**!

## Что это
Киберпанк-настолка, где вы собираете себя по частям, прокачиваете авто и питомца, сражаетесь на кубиках и пытаетесь выбраться из города до электромагнитного взрыва.
